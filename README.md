📦 NexaCode Terminal OS
⚡ A modular, glowing terminal OS for coders, built with resilience, recovery, and hacker aesthetics.


🚀 Features
🧠 Core Architecture
- 🔹 Modular Command Engine – Each command is mapped and isolated for easy debugging and upgrades.
- 🔹 Glowing UI – Neon hacker-themed interface with dark mode defaults and green-accented feedback.
- 🔹 Safe Recovery Workflow – Designed to survive crashes and rebuild from scratch, including stash recovery and Git history cleaning.
🔐 Security & Forensics
- 🔹 Encrypted .env Handling – Secrets stripped from history and safely managed via .env.example.
- 🔹 Forensic Logging – Every screen and command logs its boot status for rapid diagnostics.
- 🔹 Push Protection Compliance – GitHub-safe commits with secret scanning bypass and filter-repo integration.
